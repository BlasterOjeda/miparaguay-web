# Web independiente de Ikuaa Lo Mitã

Sitio estático preparado para `https://ikuaalomita.com.py/`. Parte de la página institucional ya publicada dentro de Mi Paraguay y conserva la propuesta de tres ciclos. La sección del canal indica que está en preparación y no presenta un enlace de YouTube inexistente.

## Archivos

- `index.html`: contenido y metadatos del dominio propio.
- `styles.css` e `ikuaa.css`: estilos generales y del proyecto.
- `script.js`: comportamiento del menú móvil.
- `assets/`: imágenes, logo y favicon necesarios para que el sitio sea autónomo.

Para probarlo, servir esta carpeta como raíz de un servidor web estático y abrir `/`. Todos los recursos internos usan rutas relativas.

## Pendiente antes de publicar

1. Confirmar el pago y la activación de `ikuaalomita.com.py` en NIC.py.
2. Crear un despliegue estático independiente para esta carpeta y asociarle el dominio. Leer los registros DNS que indique el proveedor en ese momento; no copiar los del dominio `miparaguay.com.py` sin verificar.
3. Cuando exista el canal, sustituir la tarjeta «Próximamente» por el enlace oficial de YouTube y probarlo.
4. Comprobar por separado el sitio público, las imágenes, el certificado HTTPS y la navegación móvil.

El enlace a Mi Paraguay y el correo de contacto actuales siguen apuntando a `miparaguay.com.py`. La evaluación y aprobación del MEC se describen como solicitudes, no como acuerdos vigentes.
